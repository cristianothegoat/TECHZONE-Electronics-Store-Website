# TECHZONE Electronics Store

A full-stack electronics e-commerce website built using **React (Frontend)** and **Strapi (Backend CMS)**.

## 🚀 Features

- Product listing and categories
- Product detail pages
- Shopping cart functionality
- Backend content management with Strapi
- Responsive UI

## 🛠 Tech Stack

Frontend:
- React
- JavaScript
- CSS

Backend:
- Strapi CMS
- Node.js
- SQLite

Tools:
- Git
- GitHub

## 📂 Project Structure
TECHZONE-Electronics-Store-Website
│
├── client # React frontend
├── server # Strapi backend
└── .gitignore


## ⚙️ Installation

Clone the repository:
git clone https://github.com/cristianothegoat/TECHZONE-Electronics-Store-Website.git


### Run Backend
cd server
npm install
npm run develop


### Run Frontend
cd client
npm install
npm start
